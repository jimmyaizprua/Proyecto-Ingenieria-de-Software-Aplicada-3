# EcoPermisos

Prototipo frontend estático para una plataforma web de gestión y consulta de permisos ambientales en Panamá.

## Archivos

- `index.html`: interfaz principal
- `styles.css`: estilos
- `script.js`: datos simulados e interacciones

## Cómo abrirlo

Abra `/home/runner/work/Proyecto-Ingenieria-de-Software-Aplicada-3/Proyecto-Ingenieria-de-Software-Aplicada-3/index.html` en un navegador o sirva la carpeta con un servidor estático, por ejemplo:

```bash
cd /home/runner/work/Proyecto-Ingenieria-de-Software-Aplicada-3/Proyecto-Ingenieria-de-Software-Aplicada-3
python3 -m http.server 8000
```
